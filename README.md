# SAAAVIBES Phase 1
Responsive multi-page starter website.
- Home, About, Projects
- Supabase email/password sign up and login
- Dashboard and account profile/password management
- Private workspace (notes/tasks currently stored only in this browser)
- SAAA AI Phase 1: basic local text commands, word count, password generation, image resize/compress
No generative AI model/API is connected. ChatGPT-level answers, image generation and generative photo editing require a model/API or local model.
Only the public Supabase publishable key is in the frontend. Never put secret/service-role keys here.
Before real public use, add and verify proper Row Level Security for each user-owned table, server-side authorization for admin functions, and cloud storage/data sync.
